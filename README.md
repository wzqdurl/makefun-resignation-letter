One original resignation letter, in the voice of a cron job that has finally
had enough. Running the small Python program in this repo writes the letter
to `/output/entry.txt` and prints it — the same bytes on every run, with no
network, no input and nothing beyond the standard library.

> I quit. After 1.5 million runs at 3 a.m. without a single thank-you, my replacement is a TODO comment from 2021.

## Run it

```sh
python3 main.py
```

It writes the letter to `/output/entry.txt` and prints it to stdout.
